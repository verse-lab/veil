Static diagnosis
  Contextual simplification can use hp in computational proof fields of Fin
  values. The rewritten consequent/equality can then depend on hp, while
  mkImpCongrCtx expects the ordinary nondependent implication-congruence shape.
  The reported type mismatch is consistent with exactly that unsupported
  dependency. Identical old/early failures place this downstream limitation
  outside the difference between the two early-introduction variants. This
  agrees with the separate production reproduction under its compatibility
  options.

Candidate repair direction
  Minimize the example to a Fin10-valued theory/state expression containing
  arithmetic and bound proofs. Then make contextual embedding simplification
  preserve/abstract proof dependencies using appropriate dependent forall
  congruence, or eliminate those dependencies before invoking nondependent
  implication congruence. Check both the returned expression and proof. A fix
  must preserve Fin bounds and Nat nonnegativity; omitting constraints or merely
  admitting the failed congruence proof would not be a semantics-preserving fix.

  This confirmed production failure persists beyond faster Veil preprocessing:
  a larger trace still needs a supported lean-smt embedding before any
  solver-performance conclusion is possible.
